# Plan a feature journey

Read `.claude/docs-harness/notion.md`, `decisions.md`, `inventory.md`, and the Notion "Docs revamp: page list".

1. Gather every current article that touches this feature.
2. Decide the page set. When variants differ in audience, gating, or setup, give each its own page and link them from a hub page.
3. For each page, set its stage coverage (Discover, Set up & try, Get value, Troubleshoot) and what is gated (plan, role, beta, inbox type).
4. Create the area's sub-page in Notion under the parent, with a "Journey and coverage" page: the page list, what each absorbs, what is new, the links between them. The WhatsApp journey is the worked precedent.
5. Update the area's rows in the Notion page list.

Rules: no em dashes. Public sources only. Unverifiable points become ⚠️ Confirm. Do not write files in the repo.
